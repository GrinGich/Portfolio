Game Project 1:
Sleeping With The Fishes

Genre: Visual Novel, Dating Sim

Engine: Tengine - Proprietary In-house Engine

Platform: PS5 - PC

Team Size: 16

Time: 6 weeks


The First Game Project from PlaygroundSquad

Sleeping with The Fishes is a visual novel with various available minigames, Your goal is to get to know the colourful cast of characters.

Developed at PlaygroundSquad by 16 students in 9 weeks.

What I did in this Project

> UI System


> 2D Objects


> Dialog Tool Using JSON


> PS5 Optimization


UI Buttons

  • Display on the screen is not native to Tengine, Thus I had to use make my own screenspace images based on half done sprites/Quads from Tengine.


  • Interaction, By Looking at the bounds of the button and checking for the mouse and the layer the button is on, I am able to get mouse interaction with the UI.

    On the Playstation 5, using a list of available buttons on the screen i can cycle though them and activate the one the controller or "List" has highlighted.


  • Designers can easily input the dialog and surrounding choices inside a JSON script.


  • Choices the designers can make are, Who is talking?, What is being Said?, Where is It being said? and what are the respons choices.
    Designers can easily also change the order of the talking to easily pt in new lines where needed.


  • Translation from JSON reads the them in order specified and inputs the data read into a dialog struct list, this is where the background and pictures are set and the text accompanying the dialog is stored.
    Translation happens on build and on run to make it easy to test and iterate on, making the dialog develpoment seamless for designers.
