Enemy Navigation Behaviour





  • Navigation for the enemies are based around the navmesh areas we designate.
    To avoid performance problems I remade the Unity premade navigation that calculates a new path every frame if the player moves. Into a new navigation script that calculates a new path while the enemy is moving and only starts a new calculation if the previous one is finished and set.


  • Commands made from unity actions with input from a command console in-game, type out the command and the console compares the typed out text to any existing commands and excutes them.


  • Debugging with the command console becomes easier, because the console is ingame, it means an easier time debugging,recording or any other non core gameplay task that needs doing inside builds becomes easier.


  • Designers the system is made to be easy to use for the designers, with ease of use like forcing all typed text to be lower case to make input consistent or the help command that displays all the currently available commands.
